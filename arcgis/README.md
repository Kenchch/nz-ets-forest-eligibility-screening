# ArcGIS Pro wrapper

The `.pyt` toolbox delegates to `ets_screening`; it does not reimplement rules. Install the package into the Python environment used by ArcGIS Pro, add `ets_screening.pyt` to a project, and provide three EPSG:2193 polygon inputs.

The current host did not expose an ArcGIS Pro installation, so the toolbox has been statically reviewed but not executed under `arcpy`. `layout_map.pdf` is generated by the open-source pipeline from synthetic fixtures and is explicitly not an official ArcGIS or MPI product.
