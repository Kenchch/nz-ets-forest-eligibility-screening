# Data inputs

Large raw files are deliberately excluded from Git. Download them from their publishers, retain their metadata/licence files, clip to Gisborne District, reproject explicitly to EPSG:2193, and record SHA-256 hashes in `checksums.sha256`.

| Input | Publisher | Use | Required fields |
|---|---|---|---|
| LCDB v6.0 | [Manaaki Whenua LRIS](https://lris.scinfo.org.nz/layer/123148-lcdb-v60-land-cover-database-version-60-mainland-new-zealand/) | Construct candidate polygons and `lcdb_class` proxy | `parcel_id`, `lcdb_class`, polygon geometry |
| LUCAS NZ Land Use Map | [MfE Data Service](https://data.mfe.govt.nz/) | Partial pre-1990/history cross-check | polygon geometry plus source identifier |
| Territorial authority boundary | [LINZ Data Service](https://data.linz.govt.nz/) | Clip to Gisborne District | district name and polygon geometry |
| Public conservation land | [LINZ Data Service](https://data.linz.govt.nz/) or DOC open data | Project-specific exclusion proxy | polygon geometry plus source identifier |
| Aerial imagery | [LINZ Basemaps](https://basemaps.linz.govt.nz/) | Human sample review only | WMTS or XYZ URL and attribution |

The Koordinates-based download services require an individual account/API key for some exports. Do not commit keys. The review map reads `LINZ_BASEMAP_API_KEY` from the environment.

## Expected preprocessing contract

1. Clip source layers to the Gisborne District boundary.
2. Reproject deliberately to `EPSG:2193`; the pipeline refuses to do this silently.
3. Explode multipart candidate polygons and assign a stable unique `parcel_id`.
4. Map the source land-cover label into `lcdb_class` without changing the original source column.
5. Save GeoPackage layers locally under `data/raw/` and add hashes to `checksums.sha256`.

## Demonstration data

`data/sample/` is generated by `python -m ets_screening.demo_data`. Its 12 geometries are invented NZTM shapes near Gisborne, designed to exercise area, width, pre-1990, conservation and land-cover branches. They are not cadastral parcels, LCDB observations or eligibility evidence.
